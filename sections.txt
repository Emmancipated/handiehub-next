Here are all the segments/sides of Handiehub as currently built:

User Sides / Roles
Customer — buys products/services, places orders, pays, leaves reviews
Handieman / Seller — lists products/services, receives orders, gets paid via escrow
Admin — (defined in schema UserRole.ADMIN, routes under /api/admin)

Auth Flow
Signup type selection (Customer vs Handieman)
Signup details (email, password, name, phone, country)
Login
Email verification
Logout / session (hh_session cookie)
Current user profile (/api/auth/me)

Product / Listing Flow
Browse listings (homepage featured + search)
Categories & category pages
Product detail page
Create listing (seller only) — draft status
Listing CRUD (update, delete)
Featured listings, seller's own listings

Order Flow
Create order from product detail (POST /api/orders)
Order list/tracking (my orders)
Order status: PENDING_PAYMENT → PAID → ACCEPTED → IN_PROGRESS → SHIPPED → DELIVERED → COMPLETED
Order stats/overview (admin)

Payment Flow (Paystack)
Initialize payment (POST /api/payments/initialize)
Verify payment (GET /api/payments/verify)
Paystack webhook (charge.success / charge.failed)
Checkout success/failed pages

Wallet / Ledger (Escrow)
Payment capture → escrow hold (seller funds held)
Ledger entries: PAYMENT_CAPTURE, ESCROW_HOLD, ESCROW_RELEASE, REFUND, PLATFORM_FEE, PAYOUT, ADJUSTMENT
Available balance vs escrow balance

Reviews
Leave review on delivered orders (one review per order)
Seller reviews & ratings

Addresses
User delivery addresses (default address support)

Notifications
User notifications (read/unread)

Messages / Chat
Conversations between buyer & seller
Message list with unread counts

API Route Summary (app/api/)
Route	Purpose
/api/health	Health check
/api/auth/*	signup, login, logout, me
/api/listings	CRUD + search + categories
/api/orders	Create + list orders
/api/orders/[id]	Single order
/api/orders/[id]/confirm-delivery	Confirm delivery
/api/payments/initialize	Paystack init
/api/payments/verify	Paystack verify
/api/payments/webhook	Paystack webhook
/api/users	User profile/stats
/api/wallet	Wallet balance
/api/reviews	Reviews
/api/addresses	Addresses
/api/notifications	Notifications
/api/messages	Chat messages
/api/admin	Admin routes

Pages (app/(app)/)
Home, Categories, Category detail, Handieman (pros), Seller profile, Product detail, Checkout payment, Order, Wallet, Chat, User profile, Edit profile

Auth Pages (app/(auth)/)
Login, Signup (type pick), Signup details, Verification
The shell layout (ShellLayout) provides the top nav + bottom mobile tab bar (Home, Order, Chat, Wallet, Profile).

Page	What it does
